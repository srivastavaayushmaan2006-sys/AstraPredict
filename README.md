# AstraPredict

An AI-powered Space Mission Risk Assessment Platform built to predict the probability of mission success using historical launch data, machine learning, and real-time environmental information.

## Vision

AstraPredict aims to simulate how data-driven decision systems can assist mission planners by analyzing launch conditions, vehicle characteristics, payload information, and historical mission outcomes.

## Goals

- Predict mission success probability
- Explain AI predictions using Explainable AI (SHAP)
- Visualize mission risks with an interactive dashboard
- Integrate real-time weather and public space APIs
- Deploy a production-ready machine learning application
